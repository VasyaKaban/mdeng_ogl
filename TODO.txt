Insert:
    Allocate MapNode from allocator
    fill MapNode.HashTableNode content: key, key_hash, data
    fill MapNode content: key
    insert MapNode.HashTableNode as self-allocated node
    on success: insert MapNode as self-allocated node

Delete:
    find key in HashTable
    on success release node from HashTable
    release node from Map
    delete node with Map.allocator

Scheme:
    Allocate() -> O(Count(FreeBlocks))
    Free() -> O(K where K=CountOfNeighboursBeforeMeetFreeNode(Node))

It is a generic scheme without small blocks optimization. In case of small blocks we can preallocate big heaps of memory, segment them into some fixed-size blocks and use fast push/pop scheme to allocate/free them
ex:
SegmentTable:
    0 -> 256    -> stack of blocks with size=256
    1 -> 1024   -> stack of blocks with size=1024
    2 -> 4096   -> stack of blocks with size=4096
    3 -> 65536  -> stack of blocks with size=65536
    ...
    all that is bigger than last size will go to the generic heap
    in case when we primarly allocate on startup this scheme will be OK
